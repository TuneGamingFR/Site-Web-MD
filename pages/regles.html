RÈGLES IMPORTANTES

Les règles qui contrôlent la création et la répartition des statistiques.

01 // OBLIGATOIRE

Étoiles par catégorie

Dans les nouvelles fiches, vous serez obligés d'indiquer vos étoiles dans chaque catégorie.

02 // INTERDIT

Aucune catégorie à 0

AUCUNE CATÉGORIE NE PEUT AVOIR 0 ÉTOILE.

03 // WD

22 ★ au total

Pour les WD, vous disposez d'un total de 22 ÉTOILES à répartir comme vous le souhaitez entre les différentes catégories.

04 // DD

42 ★ au total

Pour les DD, vous disposez d'un total de 42 ÉTOILES à répartir comme vous le souhaitez entre les différentes catégories, soit presque le double.

05 // DIVERSITÉ

Pas de profil uniforme

AUCUN PERSONNAGE NE PEUT AVOIR EXACTEMENT LES MÊMES ÉTOILES DANS TOUTES SES CATÉGORIES.

L'objectif est que chaque personnage possède ses propres points forts et ses propres points faibles.

06 // ANCIENS PERSONNAGES

Transition

Les anciens personnages ne sont pas obligés d'utiliser immédiatement ce nouveau système, mais vous pouvez tout de même modifier leurs fiches si vous le souhaitez.

07 // PEUT-ÊTRE

Limites futures

Une limite concernant le nombre de DD et certaines classes sera peut-être bientôt ajoutée au RP. Rien n'est encore décidé au sûr. Nous voulons plus de gens utilisant les WD.
