MURDER DRONES RP — SITE
========================
Site statique multi-pages, sans backend.

Lancer:
1. Décompresser le dossier.
2. Ouvrir index.html dans un navigateur.
3. Pour un vrai hébergement: envoyer tout le dossier sur ton hébergeur.

Pages:
- index.html : accueil
- pages/fiches.html : liste des modèles
- pages/fiche-wd.html : fiche Worker Drone
- pages/fiche-dd.html : fiche Disassembly Drone
- pages/regles.html : règlement
- pages/lore.html : lore

Personnalisation:
- Remplace les liens "DISCORD ↗" par ton invitation.
- Modifie assets/style.css pour les couleurs.
- Les fiches sont actuellement des modèles visuels; un système de comptes/formulaires/database peut être ajouté ensuite.
